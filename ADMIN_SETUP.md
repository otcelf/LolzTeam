# 🚀 Быстрый старт админ-панели

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

Это установит:
- Flask (веб-фреймворк)
- Flask-Login (система авторизации)
- python-telegram-bot (для бота)
- python-dotenv (для переменных окружения)

## Шаг 2: Запуск админ-панели

### Вариант 1: Через Python
```bash
python admin_panel.py
```

### Вариант 2: Через bat-файл (Windows)
Просто дважды кликните на файл `start_admin.bat`

## Шаг 3: Открыть в браузере

Откройте браузер и перейдите по адресу:
```
http://localhost:5000
```

## Шаг 4: Войти в систему

- **Логин**: `admin`
- **Пароль**: `admin123`

⚠️ **ВАЖНО**: Измените пароль перед использованием в продакшене!

## 🔧 Настройка

### Изменить пароль администратора

Откройте `admin_panel.py` и найдите строки:

```python
ADMIN_USERNAME = 'admin'
ADMIN_PASSWORD = 'admin123'  # Измените это!
```

Замените на свои данные:

```python
ADMIN_USERNAME = 'ваш_логин'
ADMIN_PASSWORD = 'ваш_сложный_пароль'
```

### Изменить порт

По умолчанию используется порт 5000. Чтобы изменить:

```python
app.run(debug=True, host='0.0.0.0', port=5000)  # Измените 5000 на нужный порт
```

### Отключить debug режим (для продакшена)

```python
app.run(debug=False, host='0.0.0.0', port=5000)
```

## 🗄️ База данных

Админ-панель использует SQLite базу данных `bot_database.db`.

### Таблицы:
- `users` - Пользователи
- `deals` - Сделки
- `transactions` - Транзакции
- `reviews` - Отзывы
- `appeals` - Обращения
- `verifications` - Заявки на верификацию
- `logs` - Логи действий
- `settings` - Настройки бота

База создается автоматически при первом запуске.

### Бэкап базы данных

```bash
# Windows
copy bot_database.db bot_database_backup.db

# Linux/Mac
cp bot_database.db bot_database_backup.db
```

## 🌐 Доступ из сети

По умолчанию админ-панель доступна только с локального компьютера.

Чтобы открыть доступ из сети:

1. Убедитесь, что в `admin_panel.py` указано:
   ```python
   app.run(debug=True, host='0.0.0.0', port=5000)
   ```

2. Узнайте IP адрес вашего компьютера:
   ```bash
   # Windows
   ipconfig
   
   # Linux/Mac
   ifconfig
   ```

3. Откройте в браузере:
   ```
   http://ваш_ip_адрес:5000
   ```

⚠️ **Внимание**: Не открывайте доступ из интернета без настройки безопасности!

## 🔒 Безопасность

### Рекомендации для продакшена:

1. **Измените пароль** на сложный
2. **Используйте HTTPS** (SSL сертификат)
3. **Настройте файрвол** (разрешите доступ только с нужных IP)
4. **Отключите debug режим**
5. **Используйте переменные окружения** для паролей
6. **Регулярно делайте бэкапы** базы данных
7. **Включите логирование** всех действий

### Пример с переменными окружения:

Создайте файл `.env`:
```
ADMIN_USERNAME=admin
ADMIN_PASSWORD=ваш_сложный_пароль
SECRET_KEY=ваш_секретный_ключ
```

В `admin_panel.py`:
```python
import os
from dotenv import load_dotenv

load_dotenv()

ADMIN_USERNAME = os.getenv('ADMIN_USERNAME')
ADMIN_PASSWORD = os.getenv('ADMIN_PASSWORD')
app.secret_key = os.getenv('SECRET_KEY')
```

## 📱 Использование

1. Перейдите в раздел "Обращения"
2. Выберите обращение
3. Нажмите "Ответить"
4. Введите текст ответа
5. Отправьте

## 🐛 Решение проблем

### Ошибка: "ModuleNotFoundError: No module named 'flask'"
**Решение**: Установите зависимости
```bash
pip install -r requirements.txt
```

### Ошибка: "Address already in use"
**Решение**: Порт 5000 занят. Измените порт в `admin_panel.py` или остановите другое приложение

### Ошибка: "Permission denied"
**Решение**: Запустите с правами администратора или измените права на папку

### База данных не создается
**Решение**: Проверьте права на запись в текущую директорию

### Не отображаются графики
**Решение**: Проверьте подключение к интернету (Chart.js загружается с CDN)
