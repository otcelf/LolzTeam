## 🎯 Основные компоненты

### 1. Обработчики команд
```python
CommandHandler("start", start)
```
- Обработка команды `/start`
- Deep link для покупателей
- Приветственное сообщение

### 2. Обработчики кнопок
```python
CallbackQueryHandler(button_handler)
```
- Обработка всех inline кнопок
- Навигация по меню
- Выполнение действий

### 3. Обработчики текста
```python
MessageHandler(filters.TEXT & ~filters.COMMAND, handle_text_message)
```
- Ввод реквизитов
- Ввод суммы сделки
- Ввод описания товара
- Проверка пользователей

## 🔄 Жизненный цикл сделки

```
1. Продавец создает сделку
   ↓
2. Система генерирует уникальную ссылку
   ↓
3. Покупатель переходит по ссылке
   ↓
4. Покупатель видит информацию о сделке
   ↓
5. Покупатель переводит деньги гаранту
   ↓
6. Покупатель нажимает "Я оплатил"
   ↓
7. Система проверяет оплату (10 сек)
   ↓
8. Продавец передает товар гаранту
   ↓
9. Система автоматически:
   - Переводит деньги продавцу
   - Передает товар покупателю
   ↓
10. Сделка завершена ✅
```
