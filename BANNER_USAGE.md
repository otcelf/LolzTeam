# 🖼️ Использование баннера в боте

## Описание

Баннер `banner.jpg` отправляется вместе с приветственным сообщением при команде `/start`.

## Как это работает

### 1. При запуске бота (/start):
- Бот проверяет наличие файла `banner.jpg` в корневой папке
- Если файл есть - отправляет фото с текстом в caption
- Если файла нет - отправляет обычное текстовое сообщение

### 2. При навигации по меню:
- Все последующие сообщения **редактируют caption** фотографии
- Новые сообщения НЕ отправляются
- Баннер остается на месте, меняется только текст и кнопки

## Технические детали

### Функция send_or_edit_with_banner():
```python
async def send_or_edit_with_banner(query_or_message, text, reply_markup, context=None, is_query=True):
    """
    Универсальная функция для работы с баннером
    
    Параметры:
    - query_or_message: CallbackQuery или Message
    - text: Текст сообщения
    - reply_markup: Клавиатура с кнопками
    - context: Контекст пользователя (опционально)
    - is_query: True если это callback, False если обычное сообщение
    """
```

### Логика работы:
1. **Если это callback (нажатие кнопки)**:
   - Проверяет, есть ли фото в сообщении
   - Если есть - редактирует caption
   - Если нет - редактирует текст

2. **Если это обычное сообщение**:
   - Проверяет наличие banner.jpg
   - Если есть - отправляет фото с caption
   - Если нет - отправляет текст

3. **При ошибке**:
   - Отправляет новое сообщение (fallback)

## Требования к баннеру

### Формат:
- **Имя файла**: `banner.jpg` (строго!)
- **Расположение**: Корневая папка проекта
- **Формат**: JPG/JPEG
- **Рекомендуемый размер**: 1280x640px (2:1)
- **Максимальный размер**: 10 MB

### Рекомендации по дизайну:
- Используйте яркие цвета
- Добавьте логотип Lolz Team
- Текст должен быть читаемым
- Избегайте мелких деталей
- Оптимизируйте размер файла

## Замена баннера

### Как заменить баннер:
1. Подготовьте новое изображение
2. Назовите его `banner.jpg`
3. Замените старый файл в корневой папке
4. Перезапустите бота (необязательно)
5. При следующем `/start` будет новый баннер

### Важно:
- Старые сообщения сохранят старый баннер
- Новые пользователи увидят новый баннер
- Редактирование caption не меняет изображение

## Отключение баннера

### Если нужно отключить баннер:
1. Удалите или переименуйте `banner.jpg`
2. Бот автоматически переключится на текстовые сообщения
3. Все функции продолжат работать

## Оптимизация

### Как уменьшить размер:
1. Используйте онлайн-компрессоры:
   - TinyJPG
   - Compressor.io
   - Squoosh

2. Уменьшите разрешение:
   - 1280x640 → 960x480
   - Качество 80-85%

3. Конвертируйте в WebP:
   - Меньший размер
   - Лучшее качество
   - Поддержка Telegram

## FAQ

### Можно ли использовать PNG?
Да, но переименуйте в `banner.jpg` или измените код.

### Можно ли несколько баннеров?
Да, но нужно изменить код для выбора баннера.

### Баннер не отправляется?
Проверьте:
- Имя файла: `banner.jpg`
- Расположение: корневая папка
- Размер: < 10 MB
- Формат: JPG

### Как сделать разные баннеры для языков?
Измените код:
```python
BANNER_PATH = f'banner_{lang}.jpg'
```

### Можно ли анимированный баннер?
Да, используйте GIF:
```python
BANNER_PATH = 'banner.gif'
```
