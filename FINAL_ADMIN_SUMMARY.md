## 🔌 BACKEND (admin_panel.py)

### Flask приложение:
✅ **Flask 3.0.0** - Веб-фреймворк
✅ **Flask-Login** - Система авторизации
✅ **SQLite3** - База данных
✅ **8 таблиц БД** (users, deals, transactions, reviews, appeals, verifications, logs, settings)
✅ **15+ маршрутов** (routes)
✅ **8 API endpoints** (block, unblock, approve, reject, respond, etc.)
✅ **Инициализация БД** (init_db)
✅ **Обработка ошибок**
✅ **Session management**
✅ **Декораторы** (@login_required, @admin_required)

### Маршруты:
- `GET /login` - Страница входа
- `POST /login` - Вход в систему
- `GET /logout` - Выход
- `GET /` - Главная панель
- `GET /users` - Список пользователей
- `GET /user/<id>` - Профиль пользователя
- `GET /deals` - Список сделок
- `GET /deal/<id>` - Детали сделки
- `GET /appeals` - Обращения
- `GET /verifications` - Верификация
- `GET /statistics` - Статистика
- `GET /settings` - Настройки
- `POST /settings` - Сохранение настроек

### API:
- `POST /api/user/<id>/block` - Блокировка
- `POST /api/user/<id>/unblock` - Разблокировка
- `POST /api/verification/<id>/approve` - Одобрить
- `POST /api/verification/<id>/reject` - Отклонить
- `POST /api/appeal/<id>/respond` - Ответить
- `POST /api/appeal/<id>/in_progress` - В работу
- `POST /api/appeal/<id>/resolve` - Решить
